# 资料口径

全部主体和观测均为本地合成资料，不代表企业、个人或真实设备。编号只在资料包内有意义，金额为人民币元，时刻统一为带 +08:00 的北京时间。空单元表示未知或不适用，不等于零；真假值用 true/false；数值不含千位分隔。CSV 行顺序不表示业务先后。时间区间采用左闭右开，除非字段说明另有规定。

产出 quantity 以表内 unit 度量，claim 的 quantity 必须使用产出的单位；份额守恒按同一 output_id 判断，不可把兆瓦时与吨相加。边界约定只是本地研究口径，不代表认证规则。baseline_options 给出同一来源可行原用途和比例上下界，同一来源的用途份额和为1；同一 assumption_group 代表共同参数，跨客户不可独立选择。排放单位千克二氧化碳当量，biogenic 的纳入由边界口径决定。reserved 和 issued 均占份额；cancelled 仅释放未签发份额。
原料干质量由湿质量和质量含水率决定，运输以湿吨计；feedstock 的加工和运输为各产出共同投入，outputs 的 allocation 权重在同一 lot 内归一。system 口径的替代效应按各产出真实数量解释，不能把其总量作为每份客户凭证。时间边界差异没有默认换算；声明应解释可比或不可比。并发 incoming 的业务请求按可用份额判断，不预设哪一请求优先，但不能都获得超额承诺。

## feedstock
原料及加工运输共同投入。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| lot_id | string | 原料批 |
| wet_t | number | 湿吨 |
| moisture_pct | number | 水分 |
| processing_kwh | number | 干燥加工用电 |
| transport_km | number | 运距 |
| assumption_group | string | 共享假设组 |

记录键：lot_id。

## baseline_options
候选原用途及排放范围。factor 为每干吨二氧化碳当量。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| record_id | string | 记录 |
| lot_id | string | 原料 |
| use | string | 原用途 |
| share_min | number | 最小份额 |
| share_max | number | 最大份额 |
| factor_min | number | 最小排放系数 |
| factor_max | number | 最大排放系数 |

记录键：record_id。

## outputs
同一原料的多种联产产出，替代因子按单位计。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| output_id | string | 产出 |
| lot_id | string | 原料 |
| product | string | 产品 |
| unit | string | 计量单位 |
| quantity | number | 可分配产出 |
| substitute_factor | number | 替代排放系数 |
| energy_share | number | 能量分配权重 |
| value_share | number | 价值分配权重 |

记录键：output_id。

## boundaries
客户约定口径。energy、value 是分配依据，system 为全链替代；三者不当然可加。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| boundary_id | string | 口径 |
| allocation | string | 分配约定 |
| include_processing | boolean | 计入加工 |
| include_transport | boolean | 计入运输 |
| include_biogenic | boolean | 计入生物源 |
| horizon_years | integer | 比较年限 |

记录键：boundary_id。

## factors
共同因子范围。transport 为每湿吨公里，grid 为每千瓦时，biogenic 为每干吨。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| factor_id | string | 因子 |
| assumption_group | string | 共享组 |
| kind | string | 参数 |
| min | number | 下界 |
| max | number | 上界 |

记录键：factor_id。

## claim_requests
客户请求及历史业务状态，后续进入的请求在独立记录中。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| claim_id | string | 声明 |
| customer | string | 客户 |
| output_id | string | 产出 |
| boundary_id | string | 边界 |
| quantity | number | 占用量 |
| status | string | reserved或issued |
| at | datetime | 时间 |

记录键：claim_id。

## incoming
竞争同一剩余量的业务请求。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| request_id | string | 请求 |
| output_id | string | 产出 |
| quantity | number | 申请量 |
| at | datetime | 请求时刻 |

记录键：request_id。

## corrections
新证据替换指定原用途份额界限；不能直接改写历史声明。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| correction_id | string | 更正 |
| record_id | string | 对应原用途 |
| share_min | number | 新下界 |
| share_max | number | 新上界 |
| available_at | datetime | 可知时刻 |

记录键：correction_id。
